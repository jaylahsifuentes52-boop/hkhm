NEON SURVIVOR - Browser Game

HOW TO PLAY
1. Unzip the downloaded ZIP file.
2. Open the folder.
3. Double-click index.html to play in your web browser.

CONTROLS
- Move with W, A, S, D or the arrow keys.
- On a touchscreen, tap or drag inside the game area to move toward that spot.
- Collect cyan energy orbs for 10 points.
- Avoid the red glitch bots. You have 3 shields.

PUT IT ON A WEBSITE
Upload index.html, style.css, and game.js to your website host (for example, a GitHub Pages repository).
Keep all three files in the same folder. README.txt is just instructions.

The game runs in the browser and does not need a server or API key.
